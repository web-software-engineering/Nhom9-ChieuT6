# 🚀 Hướng dẫn chạy nhanh

## Bước 1: Cài đặt dependencies

Mở terminal và chạy lệnh:

```bash
npm install
```

Đợi khoảng 1-2 phút để cài đặt các package cần thiết.

## Bước 2: Chạy ứng dụng

```bash
npm run dev
```

## Bước 3: Mở trình duyệt

Truy cập: **http://localhost:5173**

---

## 🎯 Hướng dẫn sử dụng

### 1️⃣ Mua sắm sản phẩm

1. Trang chủ hiển thị danh sách văn phòng phẩm
2. Dùng **ô tìm kiếm** hoặc **lọc theo danh mục**
3. Click nút **"Thêm vào giỏ"** trên sản phẩm muốn mua

### 2️⃣ Xem giỏ hàng

1. Click icon **🛒 Giỏ hàng** trên header (có badge số lượng)
2. Điều chỉnh số lượng bằng nút **+/-**
3. Xóa sản phẩm nếu cần bằng nút **🗑️**
4. Click **"Tiến hành thanh toán"**

### 3️⃣ Thanh toán

1. Điền đầy đủ thông tin người nhận
2. Chọn **Quận/Huyện** và **Phường/Xã**
3. Click **"Tính phí vận chuyển"**
4. Xem phí ship được tính tự động
5. Click **"Đặt hàng ngay"**
6. Lưu **mã đơn hàng** (GHN + số)

### 4️⃣ Theo dõi đơn hàng

1. Click **🔍 Tra cứu đơn** trên header
2. Nhập mã đơn hàng (VD: GHN123456789)
3. Click **"Tra cứu"**
4. Xem timeline trạng thái vận chuyển

## 💡 Tips

- **Tìm nhanh**: Gõ tên sản phẩm vào ô tìm kiếm
- **Lọc nhanh**: Click vào danh mục để lọc
- **Giỏ hàng**: Badge trên icon giỏ hàng hiển thị tổng số sản phẩm
- **Mã đơn**: Luôn bắt đầu bằng "GHN" để tra cứu
